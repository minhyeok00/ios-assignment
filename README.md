#  iOS City List Project (feat. 성능 최적화)

iOS 프로그래밍 **도시 목록 앱** 저장소입니다. 
단순히 화면을 만드는 것을 넘어, 어떻게 하면 앱이 더 가볍고 빠르게 돌아갈지 고민하며 개발했습니다. 

##  기능을 구현한 이유

### 1.- 이미지 캐싱 구현 🖼️
- **고민:** 리스트를 내릴 때마다 고화질 이미지를 새로 불러오면 폰이 힘들어하지 않을까?
- **해결:** `imagePool`이라는 딕셔너리를 만들어서, 한 번 쓴 이미지는 보관해뒀다가 바로 꺼내 쓰도록 만들었습니다. 덕분에 스크롤이 훨씬 부드러워졌습니다.

### 2. "메모리 다이어트" - 이미지 리사이징 
- **고민:** 작은 화면에 굳이 엄청 큰 원본 사진을 다 올릴 필요가 있을까?
- **해결:** 모든 사진을 보여주기 전에 `200x100` 사이즈로 딱 맞게 줄였습니다. 메모리 사용량을 확 줄인 비결입니다.

### 3. "데이터 배달" - 화면 간 정보 공유 
- 상세 화면으로 넘어갈 때 도시 정보뿐만 아니라, 메인에서 만든 `imagePool`도 같이 공유하도록 `prepare` 메서드를 꼼꼼하게 짰습니다.
